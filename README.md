# KOReader 小米 13 Ultra 全屏与摄像头避让

为小米 13 Ultra 的 KOReader 竖屏阅读移除系统黑边，同时通过同页面底色的顶部留白避开实体摄像头。

## 已验证环境

- 小米 13 Ultra，Android 16，KOReader v2026.07.2。
- 系统实际渲染尺寸为 1080 × 2400。原有分辨率设置未改动。
- 验证日期：2026-11-05；只验证竖屏阅读。

这不是通用安卓补丁。补丁仅在 KOReader 报告宽 1080、高 2292 时修正高度为 2400；它不会自动识别机型或系统刘海设置。其他设备即使报告相同尺寸，也不代表适用。

## 安装：三个步骤缺一不可

1. 手机系统设置 → 通知与状态栏 → 应用内刘海设置 → KOReader，选择“始终显示刘海”。不同系统版本菜单名称可能不同。
2. 将 `1-xiaomi-full-height.lua` 放入手机 KOReader 数据目录的 `patches/`，本次使用路径为 `/sdcard/koreader/patches/`。完全退出并重新启动 KOReader。
3. 打开书籍的底部排版菜单，进入页边距，关闭“上下边距相等”，将上边距设为 **65**，下边距保持原值（本次为 **5**）。先应用到当前书籍，再设为默认。检查当前值确实为 65；设置默认值不等于应用到当前书籍。

单独执行前两步会让文字进入摄像头区域，实体摄像头仍然会遮字。第三步让背景延伸到屏幕顶部，正文则避开挖孔。已有单独边距设置的其他书籍可能需要逐本调整。

## 原理与验证范围

系统允许应用使用挖孔区域后，KOReader 仍可能从可用高度扣除 108 像素，导致黑边由顶部移到底部。早期启动补丁修正这一特定高度值。

实机截图确认：修正后上下没有整条黑边、底部页码完整；设定上边距后，首行文字约从屏幕 y=130 开始，低于系统报告的 108 像素挖孔安全区域。实体挖孔本身不会显示在系统截图中。分页数量会因可用高度变化而改变。

横屏、PDF、其他分辨率、其他机型和后续 KOReader 版本未验证。补丁不调整菜单布局。更改分辨率或系统刘海设置后应重新检查，必要时撤销补丁。

## 撤销

删除 `patches/1-xiaomi-full-height.lua`，将系统中 KOReader 的刘海设置恢复为“自动匹配”，并重启应用。需要恢复原排版时另行恢复当前书籍和默认上边距；本次原值分别为 15 和 20。
